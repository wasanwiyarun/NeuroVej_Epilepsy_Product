# Contributing

Thank you for helping with the NeuroVej Epilepsy Product project.

This repository is public, but the open-source license is still pending owner
approval. Contributions cannot be accepted for merge until the license and
contribution terms are approved.

## Safe public participation

- Do not post personal or patient health information.
- Do not post credentials, private clinical evidence, internal risk records,
  or undisclosed vulnerability details.
- Report suspected vulnerabilities using the process in `SECURITY.md`.
- Public issues are intake records. Maintainers link accepted work to a
  controlled issue in the private documentation repository.
- Code changes require a linked issue, review, tests appropriate to the change,
  and traceability when safety or security could be affected.

No contribution may introduce or imply a medical claim that has not been
approved through the controlled lifecycle process.
