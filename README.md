# NeuroVej Epilepsy Product

Delivered product source and tests for the NeuroVej Epilepsy project.

Planned component boundaries:

- `watch/` — Amazfit Bip 6 / Zepp OS capability, if Gate G0 proves feasible;
- `mobile/` — companion mobile application;
- `detection/` — signal processing and event-detection logic;
- `backend/` — optional APIs, storage, and notifications;
- `shared/` — versioned schemas and interface contracts;
- `tests/` — cross-component integration/system test source;
- `ci/` — product build and verification pipelines.

No product implementation is authorized until intended use, system boundary,
Amazfit feasibility, initial hazards, standards applicability, and Gate G0 are
approved.

## Project status and license

This repository is public to support transparent development, but its
open-source license is not yet selected. Until a `LICENSE` file is approved and
added, no license grant should be inferred. See `CONTRIBUTING.md` before opening
an issue or pull request.
